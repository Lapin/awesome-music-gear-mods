## Akai

- [MPC60-LDK](https://github.com/fatbit1/MPC60-LDK) - Arduino add-on for chromatic play, looping and decay on the MPC60.

## Arturia

- [Hack a Brute](http://hackabrute.yusynth.net/) - Schematics and mods for the MicroBrute and MiniBrute from the designer of the analog circuits.
- [MicroBrute-Add-ons](https://github.com/MKNielsen2000/MicroBrute-Add-ons) - MicroBrute add-on boards: white noise, buffered output.
- [MicroFreak-BatteryPack](https://github.com/romix123/MicroFreak-BatteryPack) - Battery pack for the MicroFreak.
- [BeatstepExtension](https://github.com/IvoFrancx/BeatstepExtension) - BeatStep Pro add-on with eight trigger outs and random clocks.

## Casio

- [SK-1 circuit bending](https://github.com/michaelbourlotos/SK-1) - Circuit bending notes for the SK-1.
- [sk-1-octave](https://github.com/jonaspaulkarlsson/sk-1-octave) - Octave switch for the SK-1.

## Korg

- [VolcaModularMidi](https://github.com/sensai7/VolcaModularMidi) - Add MIDI in to the Volca Modular.

## Roland

- [BoutKlik](https://github.com/TheKikGen/BoutKlik) - Microcontroller box with a better chain mode for Boutique modules.
- [mc101-pisound](https://github.com/RowdyVoyeur/mc101-pisound) - Raspberry Pi add-on for audio input and routing on the MC-101.

## Teenage Engineering

- [pocket-operator-eurorack](https://github.com/rallen-device/pocket-operator-eurorack) - Mount a Pocket Operator in Eurorack.
- [Hanz Tech MIDI adapter](https://github.com/Hanz-Tech/midi-adapter-v3-hardware) - Open hardware MIDI adapter for Pocket Operators.

## Yamaha

- [reface_midi](https://github.com/matthewcieplak/reface_midi) - Patch storage box for the reface CS.
